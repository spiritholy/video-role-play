# 擦除采用"人声/伴奏分离 + 说话人掩码"方案

用户需要从源视频中擦除特定说话人的声音，同时尽量保留背景音乐和其他说话人。我们决定：先用音源分离把音频拆成人声轨与伴奏轨，再用说话人分离（diarization）结果生成目标说话人的时间掩码，只在人声轨上擦除，伴奏轨原样保留；目标说话人与他人重叠说话的时段整段擦除（目标优先）。

## Considered Options

- **A. 时间段静音**：把目标说话人的时段在原始音频上整段静音。被否决——会连带杀掉该时段的背景音乐、音效和其他人的声音，太粗糙。
- **B. 人声/伴奏分离 + 说话人掩码（选定）**：质量与可行性的最佳平衡。
- **C. 目标说话人提取 (TSE)**：用模型直接从混合音频减去目标声音，理论上可处理重叠。被否决——模型重，在纯 CPU、完全本地的约束下几乎不可行，且效果不稳定。

## Consequences

- 运行环境无 NVIDIA GPU（纯 CPU），所有模型必须能在 CPU 上以"数小时处理一部电影"的量级运行。
- 重叠语音时段其他说话人的声音会被连带擦除，这是选 B 的固有边界，不是缺陷；若未来无法接受，升级路径是 C（TSE）。
- 说话人分离选用 pyannote.audio 3.1（质量标杆），其预训练模型是门控的：需要一次性配置 HuggingFace token 并在线接受模型协议；下载后完全离线运行。
