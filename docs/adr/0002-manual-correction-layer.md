# 人工校正：生效时段之上的用户裁决层

说话人分离（pyannote）的主要失真模式是多人并入一个标签，自动手段（指定人数重跑、声纹比对）修不干净，用户需要最终裁决权。我们决定：新增**人工校正**层——用户在说话人时间轴上改段的归属（含挪给新建说话人）、拖拽调整段边界；校正结果以完整生效时段表存于工作区（生效时段 = 原始说话人分离 + 人工校正，读最上层），随工作区持久化并被同源新任务继承；仅当重新进行说话人分离（时段基础全变）时整层作废。确立**互斥归属**不变量：任一时刻至多归属一个说话人；相邻段共享边界，拖拽即移动交接点，编辑不可制造重叠。校正作用于擦除掩码与时间轴展示，不回溯样本选择与转写。

## Considered Options

- **A. 直接改写分析产物**：把校正写回说话人分离/认人产物。被否决——原始证据被覆盖，无法"放弃全部校正"回退到自动结果，也无法区分机器产出与用户裁决。
- **B. 时间锚定的操作补丁层**：存编辑操作列表，读取时重放。被否决——实现复杂一档，其唯一红利（自动认人改进可渗入未触碰的段）随 ADR-0003 声纹校验改为建议模式而消失。
- **C. 校正后完整时段快照层（选定）**：每层都是完整时段表，读最上层；作废 = 删除快照；实现最简且杜绝静默丢失。

## Consequences

- 掩码合成的"同目标跳过擦除混音"判断必须纳入校正版本，否则改了校正重擦会复用旧混音。
- 声纹校验（ADR-0003）的建议被接受后并入本层，与用户亲手编辑同等地位。
- 校正不做 undo 栈：操作本身可逆（改回去/拖回去），"放弃全部校正"（删快照）兜底。
- 批量改派（簇级错误时逐段挪几十次）是有意的 MVP 取舍，痛了就二期加批量。
