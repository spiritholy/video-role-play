# 时段删除：不做单操作撤销，仅「放弃全部校正」恢复

人工校正的段级写操作收敛为改派、切分、删除三项（见 ADR-0002）。时段删除把某个生效时段整体移除：该时间区间在时间轴留白、不再归属任何说话人，不参与擦除掩码与声纹校验；其余时段保持相对顺序不变。

## Considered Options

- **A. 单操作撤销（墓碑/局部 undo）**：为删除记录墓碑或局部撤销栈。被否决——引入墓碑生命周期与索引重排复杂度，唯一收益是删除后可单独恢复，而「放弃全部校正」已提供整体恢复路径；人工校正整体上维持不做 undo 栈的决策（ADR-0002）。
- **B. 只保留「放弃全部校正」恢复（选定）**：删除与其他校正操作共享同一个恢复路径；删除前确认弹窗明示「只能通过『放弃全部校正』恢复」，避免用户误以为可单操作撤销。

## Consequences

- 删除是不可单操作撤销的一级校正操作：确认弹窗必须提示恢复路径。
- 删除不改变其余时段的相对顺序，快照索引跨任务稳定。
- 删除后该区间不参与擦除掩码与声纹校验；擦除校验仍以其余生效时段为准。
